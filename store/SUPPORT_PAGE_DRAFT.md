## 1. 页面内容（草稿）

### 产品简介

本地优先的数字依赖关系梳理工具：帮助用户在换卡、换号、注销账户前，
识别可能受影响的支付路径并形成检查计划。全部数据仅存储在本机。

### 常见问题

| 问题 | 回答 |
|------|------|
| 我的数据存在哪里？ | 仅设备本地（SQLCipher 加密数据库）。应用无网络权限，不连接任何服务器。 |
| 应用联网吗？ | 不。Android 清单不含 `INTERNET` 权限；无 analytics / 广告 / 遥测。 |
| 如何备份数据？ | 设置内导出 `.depmap` 加密备份文件（AES-256-GCM + 你设置的口令），文件保存到你指定的位置。 |
| 如何恢复数据？ | 导入 `.depmap` → 输入口令 → 显式确认开始恢复。错误口令或篡改文件会被拒绝。 |
| 如何删除数据？ | 设置 → 「删除所有数据」；或卸载应用（本地库与密钥一并删除，无法找回——请先导出备份）。 |
| 忘记 App Lock 口令怎么办？ | 按当前实现：App Lock 口令与本地密钥绑定，忘记后无法恢复已加密数据；请务必先导出备份。 |
| 支持哪些账单格式？ | 微信账单导出 CSV、通用 CSV、OFX/QFX。文件仅在本机解析。 |
