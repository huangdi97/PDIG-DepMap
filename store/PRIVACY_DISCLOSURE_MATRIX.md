# PRIVACY_DISCLOSURE_MATRIX.md — 隐私披露事实清单（按平台）

> **用途**：为各商店的隐私问卷提供**事实依据**。本文件**不代填问卷**，也不做自动提交。
> 所有"否"必须能在代码中找到依据（`check:network` / 代码审计）。

---

## 1. 通用事实（三端一致）

| 问题                   | 事实                                     | 依据                                          |
| ---------------------- | ---------------------------------------- | --------------------------------------------- |
| 是否收集个人数据？     | **否**（无账号、无上传）                 | 无网络请求；`check:network` 0 命中            |
| 是否上传数据到服务器？ | **否**                                   | 同上                                          |
| 是否使用账号体系？     | **否**                                   | 无登录代码                                    |
| 是否有第三方分析 SDK？ | **否**                                   | `package.json` 无相关依赖                     |
| 是否有广告 SDK？       | **否**                                   | 同上                                          |
| 是否做跨 App 追踪？    | **否**                                   | 无 IDFA / GAID 访问                           |
| 是否收集设备标识？     | **否**                                   | 无相关调用                                    |
| 是否收集崩溃日志？     | **否**（本地无上传）                     | 无 crash SDK                                  |
| 是否处理金融信息？     | **是（本地）**：卡名、发卡行、卡号后四位 | 用户自填；**不保存完整卡号 / CVV / 支付密码** |
| 金融信息是否离开设备？ | **否**                                   | 无网络                                        |
| 是否加密存储？         | **是**                                   | SQLCipher / ArkData 加密 / Keychain / HUKS    |
| 是否提供删除？         | **是**                                   | 设置 → 删除全部本地数据（见 §4 限制）         |
| 数据是否加密备份？     | **是**                                   | Argon2id + AES-256-GCM                        |

## 5. 已知限制（必须如实披露，不得掩盖）

| #   | 限制             | 说明                                                                                              |
| --- | ---------------- | ------------------------------------------------------------------------------------------------- |
| L1  | 导入解析未接入   | 本版本导入流程不写入数据                                                                          |
| L2  | 备份加解密未接入 | 本版本导出 / 恢复不可用                                                                           |
| L3  | 删除范围         | 当前实现清空数据表；**密钥与数据库文件删除需在发布前补齐**（`docs/PRIVACY_RELEASE_AUDIT.md` P-1） |
| L4  | 未真机验证       | 平台安全能力（Keystore / Keychain / HUKS / 生物识别）未在设备上验证                               |

> **发布决策**：L1–L4 是否可接受，需用户明确确认（`STORE_EXTERNAL_BLOCKERS.md` B19）。

## 6. 禁止出现在任何商店材料中的表述

- "绝对不会泄露" / "100% 安全" / "绝对安全"
- "银行级安全"
- "官方银行合作" / "已接入 N 家银行"
- "自动管理你的银行账户"
- 任何虚构的奖项、用户数量、认证

依据：`docs/PRIVACY_POLICY_DRAFT.md` §9、`docs/USER_NOTICE_DRAFT.md` §2。
