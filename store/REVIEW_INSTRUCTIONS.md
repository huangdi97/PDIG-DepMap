## 1. 这是什么应用

「个人数字依赖图」（PDIG / DepMap）是一个**本地优先**的工具类应用：

- 用户导入本人账单文件（微信 CSV 等）后，应用在**本机**解析并整理出
  **已确认**的数字依赖关系（哪些服务用哪张银行卡/手机号）。
- 提供场景化检查：更换银行卡 / 银行卡即将到期 / 注销银行卡 / **更换手机号**，
  展示受影响关系与需要处理的事项。
- 变更计划按顺序执行（必须先完成 → 等待验证 → 验证后才能移除旧路径），
  完成后由用户人工验证。

## 2. 给审核人员的快速指引

| 检查点 | 预期行为 |
| --- | --- |
| 首次启动 | 无账号注册；直接在本地解锁（设备生物识别/密码，可跳过） |
| 权限 | **无网络权限**（Android 清单不含 INTERNET）；仅文件读取（导入/备份）与设备凭据 |
| 数据 | 全部存储在本机加密数据库；**无账号、无云同步、无遥测、无广告** |
| 导入 | 用户自选账单文件；解析结果先作为**建议**，由用户确认后才写入 |
| 核心主张 | 不自动发现所有依赖、不给出“安全分数”、不声称“绝不遗漏” |

## 3. 数据安全口径（给商店表格）

- **收集**：否（无个人数据上传；应用不连接网络）。
- **分享**：否。
- **删除**：应用内提供“删除所有数据”；卸载即清除本地数据。
- **儿童**：建议内容分级“全部年龄”（无用户生成内容、无社交、无购买）。

## 4. 测试账号 / 测试数据

- **无需测试账号**：应用不联网、不注册。
- 审核者可导入仓库 `fixtures/import/normal-wechat.csv`（合成数据，非真实账单）
  快速体验：导入 → 待确认服务 → 场景中心（更换手机号）→ 变更计划 → 备份/恢复。

## 5. 已知边界（避免审核误解）

- 不提供财务/投资建议，不代替任何支付或注销操作。
- “服务商支持某项能力 ≠ 你已配置该项能力”；未确认的能力不会自动成为依赖。
- 备份文件由用户自行设置口令加密；口令丢失无法找回。
