# SCREENSHOT_PLAN.md — 商店截图计划

> 现状：**无法生成实际截图**（无 HBuilderX / 无 Web-H5 运行环境 → B10/B1）。
> 本文件给出截图场景、文案与拍摄要求；待运行环境可用后执行。
> 生成的截图用于**商店素材**；用于 UI 审计的截图另见 §5。

---

## 1. 素材要求（通用）

| 平台        | 数量                   | 尺寸                        |
| ----------- | ---------------------- | --------------------------- |
| Google Play | 4–8 张                 | 手机 1080×1920 或 1440×2560 |
| App Store   | 3–10 张（6.7" + 5.5"） | 1290×2796 / 1242×2208       |
| AppGallery  | 3–8 张                 | 按 AGC 规范                 |

要求：真实界面截图（不得伪造界面）；中文；不得出现测试数据 / 内部 ID / 调试信息。

---

## 2. 截图场景（按顺序）

| #   | 页面           | 画面要点                                            | 建议叠字               |
| --- | -------------- | --------------------------------------------------- | ---------------------- |
| 1   | 首页           | 「需要你处理」有 1–2 项；「即将到来」显示一张卡到期 | 换卡之前，先看清影响   |
| 2   | 场景中心       | 三个场景卡 + 描述                                   | 从一个实际变化开始     |
| 3   | 计划详情       | 状态标签 + 影响 + 要做的事 + 下一步按钮             | 哪些必须处理，一目了然 |
| 4   | 即将到来       | 多条时间线事项（到期 / 刷新 / 计划）                | 重要时间点不会忘       |
| 5   | 可能发生了变化 | 一张 drift 卡 + 四个选项                            | 发现变化，由你确认     |
| 6   | 数据与隐私     | 隐私说明页                                          | 数据默认在本机处理     |

**备选**：待确认服务、备份与恢复、关于。

---

## 3. 拍摄准备（合成数据）

截图使用的数据必须是**明确标记的合成数据**，且**不得污染真实用户数据**：

- 在独立测试环境 / 独立设备上构建
- 合成对象名（例如"示例银行信用卡"），不使用真实卡号 / 真实商户
- 拍摄完成后重置本地数据

> 依据 §77：Release build 默认不得把 synthetic fixture 写入用户 Graph。

---

## 4. 质量检查

- [ ] 无内部 ID / UUID / 枚举 / JSON
- [ ] 无调试信息 / localhost / mock 字样
- [ ] 无真实卡号、真实商户、真实姓名
- [ ] 中文无截断、无错别字
- [ ] Safe Area 正常（无刘海遮挡、无底部指示条压字）
- [ ] 状态栏时间统一、电量一致（可选）
- [ ] 与 `store/STORE_LISTING_ZH.md` 文案不冲突

---

若后续具备 Web-H5 或模拟器环境，优先为以下页面生成**审计用**截图：

用于：UI 一致性检查、视觉回归基线。
**不直接当作商店截图**（可能含合成数据或状态不全）。
