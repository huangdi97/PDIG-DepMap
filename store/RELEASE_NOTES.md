# RELEASE_NOTES.md — 版本说明

---

## 0.3.0-rc.1（Release Candidate 1）

首个发布候选版本。

**核心能力**

- 场景中心：更换银行卡 / 银行卡即将到期 / 注销银行卡
- 变更计划：影响清单、必须处理与建议确认分开、逐步处理、完成后验证
- 即将到来：卡到期、计划时间点、数据来源刷新
- 变化提示：观察到新证据时提示"可能发生了变化"，由你确认后生效
- 待确认服务 / 待确认关系：机器推断需要你确认后才写入
- 备份与恢复：加密 `.depmap` 文件（口令由你设置）
- 数据与隐私说明页、关于页

**本次变化（相对 MVP03 收口轮）**

- 新增一级导航（首页 / 场景 / 计划 / 我的）
- 新增首次使用引导（3 屏）
- 首页改为回答式：先回答"有没有需要处理的事"
- 计划详情新增「本次分析依据」与按状态分化的下一步按钮
- 新增「待确认服务」「数据来源」「备份与恢复」「数据与隐私」「关于」页面
- 统一设计系统与组件库；统一空态 / 错误态 / 加载态
- 建立 UI 静态检查（禁止工程词、禁止页面直连数据库、禁止非 token 颜色等）
- 修复：计划详情未定义变量、不可用的 ID 生成 API、数据库接口名不匹配、启动时多余日志

**已知限制（重要）**

- 本机账单解析模块仍在接入中，**导入流程暂不会写入任何数据**。
- 文件加解密模块仍在接入中，**备份导出与恢复暂不可用**。
- 应用图标与启动图尚未提供。
- 本版本尚未在真机上完成验证。

**不包含**

- 无账号、无网络请求、无统计、无广告、无云端同步
- 不提供投资 / 财务建议，不代你执行任何支付或注销操作
