## 0.3.0（Developer Preview，Pre-release）

**核心能力**

- 场景中心：更换银行卡 / 银行卡即将到期 / 注销银行卡 / **更换手机号**
- 更换手机号采用「先建立并验证新路径，再停用旧路径」的顺序闸门（必须先完成 / 等待验证 / 验证后才能移除旧路径）
- 基础设施薄弱点：唯一恢复来源、共享故障点、恢复循环（仅依据你已确认的关系生成）
- 变更计划：影响清单、必须处理与建议确认分开、逐步处理、完成后验证
- 即将到来：卡到期、计划时间点、数据来源刷新
- 变化提示：观察到新证据时提示"可能发生了变化"，由你确认后生效
- 待确认服务 / 待确认关系：机器推断需要你确认后才写入
- 备份与恢复：加密 `.depmap` 文件（口令由你设置）；支持备份→恢复→重新打开全链路
- 数据与隐私说明页、关于页

**v0.3.0 变化（相对 0.2.0）**

- 新增能力维度：支付 / 账户访问 / 登录认证 / 恢复 / 通讯
- 新增关系：恢复方式 / 登录认证 / 控制权
- 新增「更换手机号」场景与「基础设施薄弱点」页面（Android / Desktop / iOS 四端 UI 已实现）
- 应用逻辑 Schema 升级 v4（旧文件自动迁移，`.depmap` 容器协议不变）
- 动作前置顺序在计划中以人话展示（必须先完成 / 完成后才能继续 / 可以并行处理）

**已知限制（如实披露）**

- 本版本为 Developer Preview：无真实用户、真实账单数据验证（测试全用合成 fixture）
- 未上架：商店提交需要开发者账号与正式签名（外部 Gate）
- HarmonyOS 无模拟器镜像：4 条设备门禁用例（Argon2id 原生 / ArkData）未在本机执行
- iOS 真机 LocalAuthentication / Keychain 未在真机验证（需 macOS 真机）
- Windows 安装包未签名（SmartScreen 提示）

**不包含**

- 无账号、无网络请求、无统计、无广告、无云端同步
- 不提供投资 / 财务建议，不代你执行任何支付或注销操作
