## 修复的 4 个生产缺陷

1. **`generic-csv/adapter.ts` `matchFormat()` 永远无法匹配日期**
   先替换 token 成 `(\d{4})` 再整体正则转义 → 捕获组被破坏成 `\(\d\{4\}\)`。
   后果：所有映射 CSV 全部静默判为 bad date，产出 0 观测。改为 `compileFormat()`：
   先切分字面量/token，只转义字面量，再拼装。
2. **`positiveDirection` 声明未生效** — `signed` 分支硬编码符号判定，
   "消费记正数"的发卡行导出一律方向反转。零金额改判 `neutral`，不猜。
3. **`ofx/adapter.ts parseOfxAmount('')` 返回 0** — `Number('') === 0` 通过
   `Number.isFinite`，缺失金额被伪造成 0 元交易。
4. **`import-coordinator.ts` 批内重复指纹假冲突** — `insertBatch` 批内去重，
   preview 只查 DB；含重复 FITID 的真实账单整体导入失败。preview 现对齐 insertBatch。

## 关键运维发现（重要）

`feat/mvp02-global-source` 的 loose ref（`.git/refs/heads/feat/`）在本工作区
会被外部进程反复删除 → git 把已有提交误判为 root commit、分支看似"无提交"。
**对象始终完好**（reflog 可完整找回）。
规避：分支 ref 固化在 `.git/packed-refs`。
⚠️ 再次出现时从 reflog 取哈希重写 packed-refs，**绝不** `reset --hard` / `clean -fd`。
