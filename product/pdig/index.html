PDIG 0.3.1 Developer Preview

在换卡、换号、换邮箱、注销账户之前，告诉用户哪些账户、支付路径和依赖会受到影响，以及应该先处理什么。

场景中心

模拟「更换银行卡 / 更换手机号 / 注销银行卡」等变更，生成可以按顺序执行的变更计划。

更换手机号

Make-Before-Break：先建立并验证新手机号的恢复路径，才能停用旧手机号。

基础设施薄弱点

唯一恢复来源（SPOF）、共享故障点、恢复循环——全部只依据已确认的现实关系生成。

变更计划

动作之间显示前置关系的人话：必须先完成 / 等待验证 / 可以并行处理。

导入账单

支持微信账单 CSV / OFX 等格式；导入数据只在本机处理，逐条候选由你确认。

备份与恢复

.depmap 加密容器（Argon2id + AES-256-GCM），跨桌面 / Android 恢复。

隐私优先

  • 无账号、无后端、无云同步、无遥测、无广告。
  • 数据仅存于本机加密数据库（SQLCipher / Keystore / Keychain / HUKS）。
  • 导入的账单只用于生成候选，不持久化单笔交易。
  • 详见 隐私政策。
