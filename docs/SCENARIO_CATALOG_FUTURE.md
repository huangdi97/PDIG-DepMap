# SCENARIO_CATALOG_FUTURE.md — 未来场景目录（只设计，不实现；MVP03 §38）

> 本目录全部为 **planned**：不进入 `src/scenarios/registry.ts` 可执行注册、
> 不出现在 production UI、不承诺时间表。转正流程见 SCENARIO_TEMPLATE_POLICY.md。

## 身份与联系方式

| 模板       | 说明                                            | 依赖能力                            |
| ---------- | ----------------------------------------------- | ----------------------------------- |
| 更换手机号 | 检查以该号码为验证/恢复锚点的账户；短信验证依赖 | access/recovery/identity capability |
| 手机号停用 | 停用前必须解绑的账户清单                        | 同上                                |
| 更换主邮箱 | 邮箱作为登录/恢复主键的账户迁移                 | 同上                                |
| 注销邮箱   | 注销前的恢复路径切断风险清单                    | 同上                                |

## 设备

| 模板         | 说明                                   | 依赖能力           |
| ------------ | -------------------------------------- | ------------------ |
| 换手机       | 迁移验证器/安全密钥/支付 token         | identity + payment |
| 手机丢失     | 紧急冻结路径（支付 token、已登录会话） | 同上               |
| 旧电脑出售   | 本地凭据/会话清除检查表                | access             |
| 安全密钥丢失 | 备份密钥与恢复路径验证                 | recovery           |

## 工作学习

| 模板         | 说明                                             |
| ------------ | ------------------------------------------------ |

## 国际生活

| 模板             | 说明                             |
| ---------------- | -------------------------------- |
| 搬到另一个国家   | 支付区域/税务身份/服务可用性检查 |
| 换海外手机号     | 同「更换手机号」+ 国际区号依赖   |
| 关闭海外银行账户 | 关闭前迁移扣款与收款             |

## 数字资产
