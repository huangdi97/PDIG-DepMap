# 隐私与安全（PRIVACY_AND_SECURITY）

本页面用普通语言说明 PDIG 如何处理你的数据，以及它保护了什么。

## 数据在哪里处理

- **所有处理都在你本机完成**。PDIG 不上传账单、不上传你的确认信息。
- 不需要联网（Android 版没有任何网络权限；Windows 版不连接任何服务）。

## 保存什么 / 不保存什么

| 数据 | 处理方式 |
| --- | --- |
| 你选择的账单文件 | 只在本机解析，会话结束即释放；**不长期保存原始流水** |
| 完整交易明细 | **不会保存成历史账本** |
| 分析所需的摘要与证据 | 保存在本机加密数据库中 |
| 你确认的关系 | 保存在本机加密数据库中 |
| 备份文件 | 加密容器（.depmap），你自己保存与保管 |

## 加密与密钥

- 本机数据库使用**加密存储**（Android 用设备级加密数据库；Windows 落盘只有加密容器）。
- 备份文件使用你设置的密码加密（业界标准算法：Argon2id 密钥派生 + AES-256-GCM）。
- 密钥**不会**写入源码、日志或配置文件；也不会通过任何网络发送。
- Android 解锁使用系统生物识别/设备凭据，应用不会采集你的指纹信息。

## 权限

- Android 版仅使用：生物识别（解锁用）。**没有**网络、通讯录、位置、存储等权限。
- Windows 版只在你主动选择文件时访问该文件。

## 隐私红线

- 不采集匿名统计、不埋点、无广告。
- 不把"机器推断"冒充"现实"：所有发现都以**待确认**呈现，只有你确认后才成为你的依赖事实。
- 删除全部数据 = 删除本机数据库、密钥、缓存与工作流状态；**不会**删除你已导出的备份文件。

## 安全模型的一句话

> 数据是你的，锁在你本机；我们看不见，也拿不到。
> 请保管好：设备解锁凭据、数据文件密码、备份密码（密码无法找回）。
