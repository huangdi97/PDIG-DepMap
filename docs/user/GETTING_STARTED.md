# 快速开始（GETTING_STARTED）

欢迎使用 PDIG（个人数字依赖图）。本指南用 5 分钟带你走完第一遍。

## PDIG 是什么

PDIG 帮你整理**你已经知道并确认的**数字依赖：哪些服务（比如视频会员、云盘、外卖）
在使用哪张银行卡支付。然后在**换卡、银行卡到期、注销银行卡**之前，
告诉你哪些可能受影响、哪些必须处理、哪些还需要你确认。

PDIG **不是**：

- 自动替你管理账户的工具
- 交易账本（不会把流水保存成历史账本）
- 联网的云服务（数据默认只在你本机处理）

## 第一步：开始

- **Windows**：解压或安装后，双击 PDIG。第一次会看到"新建/打开数据文件"——请新建一个
  数据文件（会用你设置的密码加密）。
- **Android**：安装后打开，先通过设备解锁（生物识别或设备密码），然后进入首页。

## 第二步：导入数据

首页找到"数据来源与导入"：

1. 选择来源（微信账单、通用 CSV、OFX/QFX 或手动添加）
2. 选择文件（文件只在本机解析，不会上传）
3. 检查识别结果并确认

导入后，产品只会保留：分析所需的摘要、证据，以及你确认的信息。
完整流水不会保存成账本。

## 第三步：确认关系

首页"需要你处理"里出现的都是**待确认**内容：

- **待确认关系**：系统发现"某服务可能使用某张卡"，需要你确认或拒绝
- **待确认服务**：系统认为某个服务可能属于你，需要你确认或忽略
- **可能发生了变化**：之前确认的信息与最近观察不一致

确认/拒绝是你的决定。机器不会自动认定现实关系。

## 第四步：发起一个场景

首页"常用场景"里有三个入口：

- **更换银行卡**：换卡前检查支付、订阅和钱包依赖
- **银行卡即将到期**：到期前看看还有哪些支付关系依赖这张卡
- **注销银行卡**：注销前确认哪些支付关系需要迁移

选择一张卡并开始分析，你会看到四类结果：**必须处理 / 可能还有其他可用方式 /
需要确认 / 当前未发现影响**。

## 第五步：备份

任何时候都可以备份：设置 → 备份。备份 = 一份加密的 .depmap 容器，
用你设置的密码加密。**密码无法找回**，请一定保管好。

## 数据怎么处理

| 内容 | 行为 |
| --- | --- |
| 你选择的文件 | 只在本地解析，会话结束即释放，不长期保存 |
| 完整流水 | 不保存为历史账本 |
| 分析摘要 / 证据 / 你的确认 | 保存在本地加密数据库中 |
| 备份文件 | 加密容器，可自行保存到任意位置 |

了解更多：导入见 `IMPORT_GUIDE.md`，场景见 `SCENARIO_GUIDE.md`，
备份恢复见 `BACKUP_RESTORE_GUIDE.md`，隐私见 `PRIVACY_AND_SECURITY.md`。
