# 导入指南（IMPORT_GUIDE）

把数据放进来，是为了让影响分析有依据。导入只做一件事：**把账单文件转成"待确认"的素材**。

## 支持的数据来源

| 来源 | 适合什么数据 | 格式 |
| --- | --- | --- |
| 微信账单 | 微信支付明细（含"交易时间/收-支"表头的导出文件） | CSV/TXT |
| 通用 CSV | 任意带表头的 CSV（日期、金额两列） | CSV |
| OFX/QFX | 银行导出 | OFX/QFX |
| 手动添加 | 单条记录 | 手动录入 |

## 流程

1. **选择来源**：在导入页选一个来源（或新建来源名称）。
2. **选择文件**：点击"选择文件并解析"，从系统文件选择器选中文件。
3. **检查识别**：
   - 会先展示识别到的对象数量（支付方式、收款对象）。
   - CSV 文件会显示"字段对应"：系统自动认出的日期/金额列，你可以修改。
   - 有无法识别的行会显示"N 行被跳过"——**跳过的行不会参与分析**。
4. **确认导入**：确认后，系统记录对象并生成**待确认关系**。

## 隐私

- 文件只在你本机解析，**不会上传**。
- 完整流水**不会保存成历史账本**。
- 只保留：分析所需的摘要、证据，以及你确认的信息。

## 常见问题

**文件读不出来？**
可能是被占用或损坏。关闭占用程序后重试。

**提示格式无法识别？**
先确认文件是上面四种之一；CSV 需要包含日期和金额两列的表头。

**部分行被跳过？**
跳过的行不会参与分析；可以把问题行修正后重新导入。

**导入后什么都没"确认"？**
正常。导入产生的是候选与待确认关系，需要你在"需要你处理"里逐条确认。

## 导入完成之后

首页"需要你处理"和"可能发生了变化"会出现待确认内容。
确认关系后，这些才参与影响分析。
