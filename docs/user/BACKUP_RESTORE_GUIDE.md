# 备份与恢复指南（BACKUP_RESTORE_GUIDE）

## 备份是什么

备份 = 把你本机加密数据库里的**已确认信息**打成一个加密的 `.depmap` 容器文件，
存到你自己选择的位置（U 盘、网盘、另一台电脑都可以）。

**备份里面有什么**：你确认的对象、依赖关系、待确认关系的状态、计划与验证状态等。
**备份里没有什么**：原始账单流水（从来不保存）。

## 密码为什么重要

- 创建备份时，你设置一个**密码**。
- 备份文件用这个密码加密——**没有这个密码，任何人也读不出内容**（包括我们）。
- **密码无法找回**。忘记密码 = 这个备份等于不存在。
- 请在安全的地方（比如密码管理器）保存它。

## 创建备份（Windows / Android 一致）

1. 进入 设置 → 备份与恢复 → 创建备份。
2. 设置密码并确认。
3. 选择保存位置。
4. 完成。

## 恢复会发生什么

恢复 = **用备份里的内容替换这台设备上当前的全部数据**。

- 会先做预检查（密码、文件完整性、版本）。
- 恢复前会显示摘要，让你确认。
- 不会留下"半恢复"状态：要么完整恢复，要么保持原样。

### 恢复步骤

1. 进入 设置 → 备份与恢复 → 恢复。
2. 选择备份文件。
3. 输入密码（**密码错误**会明确提示，需要重试）。
4. 查看恢复摘要。
5. 确认 → 恢复。

## 错误怎么区分

| 提示         | 意思                     | 怎么办                  |
| ------------ | ------------------------ | ----------------------- |
| 密码错误     | 密码不对                 | 重新输入正确密码        |
| 文件损坏     | 文件已损坏或不是有效备份 | 换一个备份文件          |
| 需要更新应用 | 备份由更新版本创建       | 升级应用后再试          |
| 格式不支持   | 不是本产品创建的容器     | 确认选的是 .depmap 文件 |

## 提醒

- 定期备份；备份文件要放在**不同设备**上（同一块硬盘坏了不算备份）。
- 恢复会**替换**当前数据，不是合并。
