支持与常见问题

当前版本为 Developer Preview（Pre-release）。如遇问题，请先在下方查找；未解决时到 GitHub 仓库提交 Issue。

重要提示：Windows 安装包未做代码签名，首次运行可能触发 SmartScreen 提示；.depmap 备份口令丢失后无法恢复数据。

快速开始

  1. 下载对应平台安装包（见产品页）。
  2. 「导入」→ 选择微信账单 CSV 或 OFX 文件 → 预览候选。
  3. 确认候选关系后，「场景中心」选择「更换手机号」或「更换银行卡」。
  4. 按变更计划顺序完成动作：先建立并验证新路径，再停用旧路径。
导入账单支持哪些格式？

微信支付 CSV（UTF-8 / GBK / GB18030）、通用 CSV、OFX / QFX。格式解析错误会逐行提示，不会静默丢弃。

如何备份与恢复？

「设置 → 备份」创建 .depmap 加密文件；「恢复」时选择该文件并输入口令。同一文件可在 Windows 桌面与 Android 之间恢复。

忘记备份口令怎么办？

无法恢复。口令通过 Argon2id 派生密钥，只有你能解密；没有后门。

「未来 schema」错误是什么？

备份文件来自比当前应用更新的版本。请升级应用后重试；出于安全我们不会猜测兼容旧文件。

更换手机号为什么要求先验证新手机号？

Make-Before-Break 原则：先建立并验证新的恢复路径，才能停用旧的，避免把自己锁在账户之外。

基础设施薄弱点是怎么来的？

只依据你已经确认的依赖关系计算唯一恢复来源、共享故障点与恢复循环；未确认的候选不会进入薄弱点列表。

数据会上传到服务器吗？

不会。无账号、无后端、无遥测；详见隐私政策。

如何提交反馈或 Bug？

在 GitHub Issues 提交，附上平台版本、操作步骤与截图。请勿在 Issue 中上传含敏感信息的账单文件。

已知限制（开发预览）

  • HarmonyOS 模拟器镜像不可用：部分设备能力（Argon2id 原生 / ArkData 加密存储）为真实设备验证项。
  • iOS 为 macOS CI 构建验证状态；商店提交需要开发账号与正式签名。
  • 商店提交（Google Play / App Store / AppGallery）尚未进行。
