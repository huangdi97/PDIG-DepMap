隐私政策

版本 0.3.0 · 2026-09-27 · 适用于 Windows Desktop 与 Android 平台上的 PDIG / DepMap（个人数字依赖图）Developer Preview。

1. 本地优先（Local-first）

PDIG 是纯本地应用：没有账号系统、没有后端服务器、没有云同步、没有遥测、没有广告、没有任何形式的联网上传。你的数字依赖图、账户、支付路径与变更计划只存储在你自己的设备上。

2. 我们处理哪些数据

  • 你主动导入的账单文件（例如微信支付 CSV、OFX/QFX）：仅用于在你的设备上解析并生成「候选依赖关系」。
  • 你确认的依赖关系：节点、依赖、依赖组、变更计划——这些是你确认后的现实关系，存储在本机加密数据库中。
  • 变更计划与验证记录：用于 Make-Before-Break 等场景的执行状态。

3. 导入会话与单笔交易

导入产生的原始观察数据只存在于当次会话内存中，会话结束即销毁。我们不持久化单笔交易；只保留去标识化的指纹摘要、候选状态和你确认后的图实体。

4. 存储与加密

  • Android：SQLite + SQLCipher，密钥由 Android Keystore 保护；解锁使用系统生物识别 / 设备凭据。
  • Windows Desktop：本地加密数据库 + Windows DPAPI / 设备凭据；备份文件为 .depmap 加密容器（Argon2id v19 + AES-256-GCM）。
  • 口令与密钥从不以明文写入磁盘、日志或配置文件。

5. 我们绝不收集

  • 不收集设备标识符、位置、联系人、短信、通话记录。
  • 不读取、不存储你的密码管理器内容、NFC 卡数据。
  • 不进行任何形式的自动读取短信或无障碍自动化。

6. 备份与导出

你创建的 .depmap 备份是加密容器，仅由你掌握的口令保护。请妥善保管口令；口令丢失后无法恢复数据。

7. 删除数据

应用内提供「删除全部数据」；卸载应用并删除备份文件后，数据即从本机移除。由于没有云端副本，删除是不可逆的。

8. 联系我们

隐私相关问题请通过 GitHub 仓库 PDIG-DepMap 的 Issue 与我们联系，或在 支持页面 查看常见问题。
